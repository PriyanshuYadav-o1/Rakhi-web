# ❤️ Kavya & Priyanshu — Ultimate Raksha Bandhan Website

A personalized, warm, neumorphic brother-sister website.

## Names
Sister: Kavya Yadav
Brother: Priyanshu Yadav

## Design
Premium soft neumorphism with blush pink, rich magenta, royal purple, rose-gold and warm yellow accents, plus photo memories, reels, letter, timeline, promise section and responsive mobile UX.

## 📸 Add your six photos

Put your images inside:

assets/photos/

Use these exact filenames:

1. childhood-1.jpg
2. childhood-2.jpg
3. together-1.jpg
4. together-2.jpg
5. rakhi-2025.jpg
6. favorite-memory.jpg

The photo section is automatically positioned after the "Our Story" section.

If your images are PNG or WEBP, either rename them to .jpg or change the extension in index.html.

## 🎬 Add three reels

Put vertical MP4 files inside:

assets/reels/

1. reel-1.mp4
2. reel-2.mp4
3. reel-3.mp4

Recommended: MP4/H.264, 1080x1920, 9:16.

## 🎵 Optional music

Put a royalty-free MP3 at:

assets/audio/music.mp3

The Music button will play/pause it.

## Recommended memory order

Photo 1 = oldest childhood photo
Photo 2 = funny childhood photo
Photo 3 = recent brother-sister photo
Photo 4 = casual/funny photo
Photo 5 = Rakhi photo
Photo 6 = your favorite emotional photo

Reel 1 = childhood / memories
Reel 2 = funny sibling moments
Reel 3 = emotional/family/Raksha Bandhan ending

## Run

Extract the ZIP and open index.html.

For development, use VS Code + Live Server.

## Privacy

If you deploy publicly, remember that photos and videos in the assets folder are public. Use only media you are comfortable sharing.
